# Пограничье — сборка для сайта и VK/ОК

Готовые файлы игры: корень — веб-версия, `vk/` — клиент для VK и Одноклассников. Исходный код — в репозитории студии (`games/pograniche`), сборка из коммита `e6deb4e`, 18 ноября 2026.

В VK/ОК работает реклама: баннер внизу после первого боя, межстраничная между боями по политике студии, награды за просмотр. Магазин (самоцветы, «Набор путника», «Покровительство») встроен, но настоящая оплата выключена, пока не запущен общий сервер платежей. Своей аналитики нет. Прогресс хранится в браузере под ключом `studio:pograniche` и в облаке VK.
